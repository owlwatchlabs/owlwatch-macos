# Code of Conduct

Owlwatch uses the Contributor Covenant Code of Conduct, version 2.1.

## Standards

Participants are expected to communicate professionally, focus critique on the work, and keep security discussions responsible and evidence-based.

Unacceptable behavior includes harassment, threats, discriminatory language, doxxing, sustained disruption, and public disclosure of sensitive vulnerabilities before coordination.

## Enforcement

Maintainers may remove comments, close issues or pull requests, restrict participation, or ban contributors who violate this code of conduct.

## Reporting

Report conduct concerns privately to the maintainers. Security vulnerabilities should follow `SECURITY.md` instead of this process.
